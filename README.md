# 猴子海岸骑行

一款 3D 网页小游戏。猴子沿着海岸公路自动骑行，玩家控制方向、加速和跳跃。沿途可以收集金币和血瓶，最高分保存在当前浏览器。

## 开始游戏

- 在线玩：[GitHub Pages](https://lg2879155-spec.github.io/monkey-coast/)
- 离线玩：将本仓库的 `index.html` 保存到本地，用支持 WebGL 的浏览器打开。游戏和 Three.js 都打包在这个文件里。

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 左右移动 | `A` / `D` 或方向键 | 按住左右键 |
| 加速 | 按住 `Shift` | 按住「加速」 |
| 跳跃 | `空格` | 点「跳跃」 |
| 切换预设视角 | `C` | 点「视角」 |
| 自由观察 | 左键拖拽旋转，滚轮缩放 | 单指拖动，双指缩放 |
| 暂停 | `P` 或 `Esc` | 点暂停按钮 |

靠近金币会自动拾取，连续拾取会提高得分倍率。普通碰撞扣一格血，加速时撞碎路障可得 25 分，跳得够高可以越过路障。红色血瓶回复一格血，血量上限为三格。

## 部署和许可证

站点可直接从 `main` 分支根目录部署。游戏无需构建，也不依赖后端服务。
